# Banking Data Analytics

## Project Overview

This project focuses on analyzing banking data to understand loan performance, collections, debit and credit transactions, and financial risk. I worked on two major modules: **Bank Loan Analysis** and **Bank Credit and Debit Card Analysis**.

I used Excel, MySQL, Power BI, and Tableau to prepare data, analyze financial information, calculate KPIs, and create visual dashboards to identify trends and present meaningful business insights.

## Project 1: Bank Loan Analysis

**Objective:** To analyze loan funding, interest, collections, defaults, delinquency, and loan status.

### Key KPIs

- Total Loan Amount: ₹73.27 crore
- Total Loans: 65,535
- Total Interest: ₹15.53 crore
- Default Loan Count: 1,020
- Delinquent Client Count: 7,106
- Default Loan Rate: 1.56%
- Delinquent Loan Rate: 10.84%

### Analysis Performed

- Compared loan amounts across product groups and age categories.
- Examined loan distribution by grade and loan status.
- Analyzed loan disbursement trends over time.
- Compared average loan maturity across loan statuses.
- Explored city-level revenue, interest, and fees.
- Used filters for disbursement year, state, age, grade, religion, and loan status.

## Project 2: Bank Credit and Debit Card Analysis

**Objective:** To analyze transaction amounts, transaction volumes, bank and branch performance, monthly trends, and high-risk transaction classifications.

### Key KPIs

- Total Credit Amount: ₹12.76 crore
- Total Debit Amount: ₹12.73 crore
- Total Transactions: Approximately 100,000
- Credit-to-Debit Ratio: 1.0025
- Net Transaction Amount: ₹318.12K
- High-Risk Transactions: Approximately 20,000

### Analysis Performed

- Compared monthly transaction volumes and identified changes over time.
- Analyzed the distribution of high-risk and normal transactions.
- Compared transaction activity across banks and branches.
- Examined transaction methods, including Debit Card, Credit Card, and Bank Transfer.
- Compared monthly transaction trends across branches.
- Used filters to explore banks, branches, transaction methods, dates, transaction types, and risk classifications.
