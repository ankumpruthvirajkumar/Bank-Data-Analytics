# Banking Data Analytics

## Project Overview
This project analyzes banking data to understand loan performance, debit and credit transactions, collection recovery, and financial risk. The goal is to identify trends and present useful insights through dashboards and reports.

##  To access the datasets used in this project use the link below
[data sets](https://drive.google.com/drive/folders/1TCMIE52c4cSmujMwI19aODqgmoTOYeQD?usp=drive_link)
## Tools Used
- **Microsoft Excel:** Data cleaning, preparation, and analysis
- **SQL / MySQL:** Data queries and analysis
- **Power BI:** Interactive dashboard development
- **Tableau:** Data visualization and reporting
- **PowerPoint:** Project presentation

## Project Modules

### 1. Bank Loan Analysis
Analyzed loan amounts, loan counts, collections, interest, defaults, and delinquency to understand lending performance and risk.

### 2. Debit and Credit Analysis
Analyzed debit and credit transactions to identify transaction trends, high-risk activity, bank and branch performance, and changes over time.

## Key Performance Indicators (KPIs)
- Total loan amount funded
- Total number of loans
- Collection amount and interest
- Loan default rate
- Delinquency rate
- Debit and credit transaction amounts
- High-risk transaction percentage

## Dashboard Features
- Interactive filters and slicers
- Bank and branch comparisons
- Monthly and yearly trends
- Loan performance and risk analysis
- Debit and credit transaction analysis

## Project Files
This repository contains the project presentation, dashboard screenshots, and available analysis files for Excel, SQL, Power BI, and Tableau.

## Conclusion
The project demonstrates how banking data can be cleaned, analyzed, and visualized to understand financial performance, identify potential risks, and support data-driven decisions.
